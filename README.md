# cyberDie - Digital Dice Roller
This project was completed for the ELEC-C9801 Design Thinking and Electronic Prototyping course. This repository includes the code for the firmware of the device. It includes a Wokwi diagram for prototyping, testing, and debugging the device. The firmware is intended to be built for an ESP32 with a 128x128 OLED. It can drive any display compatible with the Adafruit_GFX library.

The purpose of this project was to enhance the tabletop RPG experience by creating a physical device that reduces that distractions when using similar alternatives on mobile phones.
